# Usage story template

Use this template to share how a prompt from awesome-ai-prompts worked on a
real project. The whole point is verification: an honest before/after with
evidence, not advertising. If a prompt did not work, say what happened and what
you changed - that is a useful story too.

## The story

- **Prompt used** - `category/name-prompt.md`, with a link to the file
- **Task** - what you were trying to do, in one or two lines
- **Agent** - which AI coding agent (Claude, ChatGPT, Copilot, Cursor, opencode, ...)
- **Stack** - so readers can judge how well the prompt transfers

## Before

What the code or repo looked like when you started. A description is enough -
no need to paste a diff.

## What the prompt made the agent do

The steps it actually took, and anything it got wrong the first time.

## After

What changed, with evidence. "It passes" is not evidence. Paste the check
output, the diff, or the before/after numbers (latency, coverage, defect count,
review comments).

## Would you use it again?

One or two lines. A prompt that needs changes before reuse is worth reporting
here - that is a fix, not a failure.

## Rules

- Write it yourself. These stories are yours because the evidence is yours.
- Name the prompt and the agent. A story that could be about anything proves
  nothing.
- Verification over adjectives: commands, numbers, and links beat claims.
- Keep it under 200 words. One story per PR.

---

Open a pull request with your story filled in, or drop it in a discussion if a
PR feels like too much. Either way, keep the verification - the evidence is the
point.
