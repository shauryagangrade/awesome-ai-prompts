# Career & learning

Prompts for getting hired and getting better: interviews, resumes, portfolios, blog posts, roadmaps, and conference talks.

Back to the [main index](../README.md#career--learning) or browse
[every prompt on one page](../website/index.html).

## Prompts

- [code-interview-practice-prompt.md](code-interview-practice-prompt.md) - structured interview coaching with hints on demand.
- [portfolio-project-prompt.md](portfolio-project-prompt.md) - shape an idea into a scoped, presentable portfolio project.
- [resume-review-prompt.md](resume-review-prompt.md) - review a technical resume: impact bullets, keyword density, honesty.
- [tech-blog-writer-prompt.md](tech-blog-writer-prompt.md) - turn a project or technical concept into a clear, engaging blog post.
- [learning-roadmap-prompt.md](learning-roadmap-prompt.md) - turn a skill gap into a project-based roadmap with verifiable checkpoints.
- [conference-talk-proposal-prep-prompt.md](conference-talk-proposal-prep-prompt.md) - write a competitive CFP and rehearse the talk: hook, takeaway, timed outline, demo fallbacks.

- [mentoring-feedback-prompt.md](mentoring-feedback-prompt.md) - give structured, verifiable feedback to a junior engineer with evidence.$
- [interview-debugging-drill-prompt.md](interview-debugging-drill-prompt.md) - coaching a real debugging session: reproduce, form/test hypotheses, prove root cause, minimal fix, regression test, explain thinking.
